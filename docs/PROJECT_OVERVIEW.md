# AgriRow Vision 项目概览

## 项目简介

AgriRow Vision 是一个面向智能农机自动对行任务的计算机视觉系统原型。项目围绕田间作业中的作物行感知问题，探索如何从车载相机画面中估计作物行相对农机中心的横向偏移，并将感知结果用于实时监控和控制系统交互。

项目将图像处理、目标检测、边缘设备通信和桌面端可视化整合在同一套系统中，形成从视频输入到偏移信息输出的完整原型链路。

## 研究背景

农机进行除草、播种和田间管理时，需要沿作物行稳定行驶。人工驾驶容易受到作业时长、光照变化、作物遮挡和驾驶员经验等因素影响。基于视觉的自动对行方法可以持续获取作物分布信息，为农机转向控制、精准除草和作业质量监测提供依据。

该任务不仅涉及目标检测精度，还需要解决相机透视畸变、物理尺度映射、实时计算、边缘端部署和工业设备通信等工程问题。

## 技术路线

```text
摄像头或视频流
       │
       ▼
图像去畸变与鸟瞰变换
       │
       ▼
作物目标检测
       │
       ▼
作物行中心与横向偏移估计
       │
       ▼
实时界面显示与历史曲线
       │
       ▼
边缘设备及 PLC 控制接口
```

系统首先采集本地摄像头、视频文件或边缘设备输出的视频帧，再根据相机参数完成去畸变和鸟瞰视角转换。检测模型用于提取作物目标位置，系统进一步计算作物区域中心与画面中心之间的横向偏差，并通过 PyQt5 界面展示实时画面、偏移曲线、设备状态和运行日志。

通信部分采用 TCP Socket，将模型启停、参数同步、系统切换和 PLC 控制等操作封装为独立指令，并通过视频通道接收边缘设备返回的图像与预测信息。

## 主要工作

- 设计智能农机视觉对行系统的整体数据流程和客户端架构。
- 实现相机图像去畸变、鸟瞰视角转换及相关参数配置。
- 实现基于检测结果的像素级横向偏移计算与实时曲线展示。
- 实现本地摄像头、视频文件和远端视频流的接入原型。
- 实现基于 Socket 的指令通信、视频通信和参数同步模块。
- 使用 PyQt5 实现监控画面、参数设置、日志管理和设备状态界面。
- 整理系统数据流图、界面原型和边缘设备部署方案。

## 系统特点

| 方向 | 实现内容 |
| --- | --- |
| 视觉感知 | 目标检测、图像去畸变、鸟瞰变换和偏移估计 |
| 实时交互 | 视频显示、偏移曲线、参数配置和状态监控 |
| 边缘协同 | 面向国产边缘设备的视频与指令通信接口 |
| 工业控制 | 预留模型管理、参数同步和 PLC 控制接口 |
| 工程设计 | 保存数据流图、界面设计图和模块化代码结构 |

## 当前成果

项目已完成智能农机视觉对行客户端及关键算法链路的原型实现，能够展示视频处理、目标检测、鸟瞰变换、偏移计算、实时可视化和设备通信等核心模块。

当前公开仓库主要用于展示系统设计与工程实现。作物专用数据集、自训练模型权重、边缘设备服务端和 PLC 程序未包含在仓库中，因此现有代码更适合作为系统原型和后续实验基础，而不是可直接投入生产的完整控制系统。

## 进一步研究方向

- 引入语义分割或作物行结构拟合，提高缺苗、杂草和遮挡情况下的偏移估计稳定性。
- 建立像素偏移到实际横向距离的标定方法，并分析相机参数误差对结果的影响。
- 构建覆盖不同地块、生育期和光照条件的数据集与评价体系。
- 研究模型在国产边缘设备上的精度、速度、功耗与端到端时延。
- 将模型置信度、通信状态和异常检测纳入控制策略，完善安全降级与人工接管机制。

## 项目定位

本项目的重点不只是单一视觉模型，而是探索计算机视觉算法如何与相机几何、边缘计算、实时界面和工业控制系统结合。通过该项目，我对视觉算法从实验验证走向实际设备部署所涉及的数据、算法、软件和硬件问题形成了较为系统的认识。
